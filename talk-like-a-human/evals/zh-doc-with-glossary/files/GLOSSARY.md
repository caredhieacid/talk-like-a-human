# 术语表

同一个东西只用一个叫法。

| 标准叫法 | 不要用的叫法 | 例外 | 代码里叫 | 意思 |
| --- | --- | --- | --- | --- |
| 工作区 | 空间、团队空间、项目组、workspace | 存储空间 | `Workspace` | 一组项目和成员。计费按工作区算。 |
| 成员 | 组员、团队成员账号 | | `Member` | 被邀请进某个工作区的人。 |
| 项目 | 工程、仓库 | | `Project` | 工作区里的一个工作单元。 |
| 管理员 | 管理者、admin、超管 | | `Admin` | 创建工作区的人，能邀请和移除成员。 |
